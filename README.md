# Energía Monstruosa

## ¿De qué trata?
Energía Monstruosa es un medidor de gritos inspirado en el universo de Monsters, Inc. El proyecto transforma la intensidad de un sonido en una señal visual para mostrar cuánta energía genera el grito.

## ¿Cómo funciona?
Un micrófono capta el sonido y el sistema lo procesa mediante Arduino. Según la intensidad detectada, se enciende una tira de luces LED. La estructura que contiene los componentes fue diseñada y fabricada mediante impresión 3D.

## Tecnologías y materiales
- Arduino
- Micrófono
- Tira de luces LED
- Visual Studio Code
- Impresión 3D

## Desafíos del proyecto
Uno de los desafíos fue integrar el micrófono, Arduino y las luces para que respondieran al sonido. También tuvimos que ajustar el diseño impreso en 3D para que pudiera contener los componentes y dejar las luces visibles.
